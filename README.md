# Equine Auction Platform - Iteration 1

A Flutter-based mobile platform designed for managing and browsing equine auction listings, 
user authentication, and catalog management.

## Project Overview
This repository contains **Iteration 1** of the Equine Auction App built as part of the 
BSc Hons Software Development capstone. The goal of this iteration is to deliver a functional 
Minimum Viable Product (MVP) covering basic account creation, administrative/user authentication, 
and horse listing management.

## Iteration 1 Features
* **User Authentication:**
    * New user registration (Sign Up screen).
    * Existing user login (Admin & standard user roles).
* **Horse Catalog:**
    * Dynamic list/grid view of active horse listings.
* **Listing Management:**
    * Administrative interface to add new horse entries with details (e.g., pedigree, age, reserve price).

## Tech Stack
* **Frontend:** Flutter (Dart)
* **Backend & Database:** Firebase
* **Version Control:** Git & GitHub

## Getting Started

### Prerequisites
* [Flutter SDK](https://docs.flutter.dev/get-started/install) (latest stable version)
* [Dart SDK](https://dart.dev/get-dart)
* Android Studio or VS Code with Flutter extensions installed

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MiloszCwynar/EquineApp
   
   cd equine_auction_app
   
   flutter pub get
   
   flutter run
   ```
